瓶頸與調校依據

Nsys：原設定 fitness kernel 平均 669.09 ms，佔 GPU kernel 時間 99.9%；此 capture 不混入正式 timing。

512 MiB region workspace 限制同時執行的 blocks。原設定 62 blocks；調校設定依程式公式可容納 79 blocks。

輸入長度 1–50；DC 每次 split 都嚴格縮短 list，長度 ≤1 結束。故本題最多需要 50 個 live frames。

僅調整 frame 上限與 block size。程式、cases、fuel 固定，production runtime 未修改。

下一步：DC interpreter、region memory 存取與 host packing／reproduction／decode；尚未證明可達 40×。
