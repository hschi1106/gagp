# Restricted evolution compatibility design

Pre-implementation inventory, 2026-09-27. The functioning Stage A source is
`2d11d4a`; initial HEAD `7c11429` adds navigation documentation only. The actual
contracts inspected are `compiled.cpp`, `variation_contract.cpp`, `donor.cpp`,
`mutation.cpp`, GPU `grammar_prep.cpp`, and the frozen representative grammars.
This is a design record; passing evidence belongs in the results report.

| Family | Stage A behavior and retained boundaries | Restricted policy |
| --- | --- | --- |
| Ordinary expressions, all eight types | Membership reconstructs production, exact type, formal lexical scope, ordinary name availability and source/physical resource charges. Authored crossover groups can bypass rule identity; complete child admission catches invalid exchanges. | Compile a conservative replacement-language certificate. A group label alone cannot permit exchange. Equivalent differently named rules share a contract; incompatible same-typed languages remain separate. Ordinary free names still need matching availability. |
| Typed payloads | Constants own decoded domains; runtime tokens are validated through payload transactions. StringList includes nested String dependencies. | Keep all payload types, mutation domains and invalidation checks. Reused preparation must own or validate payload reads; no pointer/provenance-only shortcut. |
| Traversal and nested lexical regions | Declared hole scopes carry ordered binder mappings; some traversal bodies are eligible. Proven closed payloads can cross lexical contexts. | Preserve eligible holes and closed exchanges only with a compiled replacement certificate and runtime closure proof. Bindings internal to the donor move with it; external bindings use the declared interface. |
| DC, DP1D, DP2D | General bounded plans and authored templates implement these families. Migrated phase rules disable subtree variation, while eligible constants retain separate policy. Whole structured roots can vary. | Freeze skeleton and binding layout; retain whole-family replacement, source-reachable donors and eligible constants. Do not infer a ban on every traversal body from the phase policy. |
| LinearRec-derived programs | General lexical/structured templates retain actual mapped behavior and nesting; complete materialized execution is package-independent. | Retain whole-template replacement and explicit holes. No package-name dispatch or runtime type removal. |
| Repeated holes | One logical choice has several physical occurrences; replacement is atomic and resource allowance accounts for every copy. | Keep bounded explicit repeated holes with one scope/type contract. Reject unsupported binding relationships rather than splitting mutations. |
| Donors | CPU makes a fresh selected-site donor. GPU prepares bounded per-site pools, already with unused-donor skipping, parallel jobs and prefetch. Context includes destination ordinary locals; offspring admission may inspect the full child. | Use fixed declared ordinary-local interfaces (empty by default), declared lexical binders and grammar inputs. Reuse pools only within bounded preparation lifetime and exact compatible generation/resource classes; refresh on subsequent preparation. Preserve backend route differences and disclose sampling correlations. |

Physical capacity stays distinct from source resources: the canonical mapping uses
531 nodes/depth 141 for the original 80-node/depth-7 construction budget. Local
resource admission may only be used with a proved charge invariant. External
programs and public prepared state retain full validation and ownership checks.

Templates already forbid references outside declared holes and track fixed node
origins. The implementation will make mutable constants explicit and validate the
bounded shared-hole interface, rather than claiming existing fixed-node support as
a new optimization. Existing production weights remain generation weights; shared
pools change independence and RNG trajectories, not the declared value language.

The six performance workloads remain the existing preselected p64/p1024 canonical,
mixed payload, nested binder, metadata stress and DP2D rows. Compare the immutable
Goal 01 reference, Stage A and final restricted implementation on Snoopy, retaining
all modes and recording unsupported/changed rows. No final timing has informed
this selection. Original Goal 11 acceptance remains historically incomplete.
