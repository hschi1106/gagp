# Fixed ASGP/GAGP Benchmark

`gagp_fixed_asgp_bench` runs GAGP and the original ASGP C++ solver on
identical frozen inputs: the same initial population (generated by ASGP's
own initializer and translated into the task grammar) and the same cases. It
is the benchmark behind every GAGP-vs-ASGP-1T number in this repository.

The research context (what is measured and why) is in
[research-mainline.md](../design/research-mainline.md). The full history of
this benchmark's earlier contracts, probes and optimization rounds is archived
in [fixed-asgp-history.md](../reference/fixed-asgp-history.md); it is a record,
not a set of instructions.

## Build

The adapter links the unmodified ASGP sources, so it needs the external ASGP
C++20 source tree:

```bash
cmake -S cpp -B cpp/build/release -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_CUDA_ARCHITECTURES=86 -DGAGP_BUILD_BENCHMARKS=ON \
  -DGAGP_ASGP_SOURCE_DIR="$HOME/r13921069"
cmake --build cpp/build/release --target gagp_fixed_asgp_bench -j
```

## Inputs: task, grammar, cases, population

Each task (the 30 ASGP-paper program-synthesis tasks) needs a task grammar
and frozen inputs. The pipeline is:

| Step | Command | Output |
| --- | --- | --- |
| Cases | `bench dataset TASK OUT` (`GAGP_DATASET_SEED`) | Train/test candidate pools generated by ASGP's task generator |
| Freeze | `bench freeze TASK OUT` (`GAGP_FREEZE_POPULATION=N`, `GAGP_FREEZE_POPULATION_SEED`, `GAGP_BM_CASE_COUNT`) | `source.json`: ASGP-initialized population plus cases |
| Translate | `bench prepare SOURCE GRAMMAR POP OUT` | `prepared.json`: the same programs as GAGP genotypes; every program must be admitted, none is replaced or filtered |
| Run | `bench measure SOURCE PREPARED GRAMMAR POP MODE OUT` | Result JSON (see modes) |
| Judge | `bench quality-source SOURCE EXPORT GRAMMAR OUT [HISTORY]` | Exported champions re-scored on another case file (for example the test split) on the CPU |

`GAGP_BM_CASE_COUNT` (1..4096, default 1024) declares the case count of a
source file; a mismatch is rejected. A smaller population `POP` uses the first
`POP` programs of a larger frozen population, so populations of different
sizes share their prefix. Task grammars are generated by
`tools/gagp_tools/experiments/fixed_asgp/grammar.py`; the scale experiment uses
the 2048-node versions copied into its directory.

## Modes

Search modes run a complete search (initial evaluation, `G` generations, final
population) and are the ones used for research results:

| Mode | Engine |
| --- | --- |
| `search_gpu_overlap` | GAGP mainline: resident GPU phase population (GPU reproduction + GPU evaluation) when the search configuration selects `representation: phase_population` |
| `search_phase_cpu` | GAGP CPU reference engine: same operators and random draws, CPU evaluation, no CUDA. Must publish the same champion, history and final population as `search_gpu_overlap` |
| `search_asgp_1t` | Original ASGP solver, one thread |
| `search_gagp_cpu`, `search_gpu_eval`, `search_gpu_repro` | Native-AST GAGP controls |

The five fixed-generation modes `asgp_1t`, `gagp_cpu`, `gpu_eval`,
`gpu_repro` and `gpu_overlap` time one generation of scoring plus
reproduction from the frozen parents; `snapshot` and `asgp_snapshot` score
the frozen population once (`GAGP_SNAPSHOT_CPU=1` adds a CPU audit). They are
kept as controls and diagnostics.

## Run settings

| Setting | Meaning |
| --- | --- |
| `GAGP_SEARCH_CONFIG` | Search configuration ([spec](../../spec/search_config.md)); the final profile is [`configs/search/gagp_final_asgp.json`](../../configs/search/gagp_final_asgp.json). `population_size` must equal `POP` |
| `GAGP_SEARCH_GENERATIONS`, `GAGP_BM_SEED` | Generations (default 4) and run seed; must not contradict the configuration |
| `GAGP_BM_ALIGNED_FITNESS=1`, `GAGP_BM_GPU_BLOCKSIZE=512` | The task's ASGP fitness metric with the ASGP case-error cap 1000 and elitism 1; the fitness reduction width shared by the GPU engine and the CPU reference |
| `GAGP_SEARCH_EXPORT`, `GAGP_SEARCH_EXPORT_BEST_ONLY=1`, `GAGP_SEARCH_HISTORY_EXPORT` | Champion export and per-generation history (with `elapsed_search_ms`) |
| `GAGP_HOST_THREADS=1` | One application CPU thread; required for the ASGP-1T comparison |
| `GAGP_ENGINE_PROFILE` | Defaults of the exact engine switches; `mainline` (default) or `legacy` ([details](../design/research-mainline.md#engine-switches-and-the-engine-profile)) |

`evolve_wall_ms` in the result JSON is the reported search time for every
engine: initial evaluation through the final population, excluding process
start, input loading and translation. The ASGP-1T search uses ASGP's own
operators with the same common parameters (tournament 2, crossover 0.7,
mutation 0.3, one phase per operator, depth 7, elitism 1, generational). Speedups are reported only from unprofiled runs while the
GPU lock is held.

Minimal GAGP run:

```bash
GAGP_BM_ALIGNED_FITNESS=1 GAGP_BM_GPU_BLOCKSIZE=512 GAGP_HOST_THREADS=1 \
GAGP_SEARCH_CONFIG=configs/search/gagp_final_asgp.json GAGP_BM_SEED=1 \
GAGP_SEARCH_EXPORT=out.export.json GAGP_SEARCH_EXPORT_BEST_ONLY=1 \
GAGP_SEARCH_HISTORY_EXPORT=out.history.json \
cpp/build/release/gagp_fixed_asgp_bench measure \
  inputs/median/s1.source.json inputs/median/s1.prepared.json grammars/median.json \
  1024 search_gpu_overlap out.json
```

Replacing the mode with `search_phase_cpu` must reproduce `out.export.json`
byte for byte and `out.history.json` except for its `*_ms` fields.

## Scale experiment

The final experiment (P = 1024, 4096 and 16384; 1024 training cases; 30 tasks;
5 seeds; GAGP GPU vs GAGP CPU reference vs ASGP-1T) and its harness are in
[`benchmarks/final-scale-20261103/`](../../benchmarks/final-scale-20261103/README.md).

## Ownership

- `cpp/src/bench/fixed_asgp/`: adapter, translation and timing. It defines no
  runtime semantics.
- `tools/gagp_tools/experiments/fixed_asgp/`: task grammar authoring and the
  older daily/scaling runner (`tools/tests/test_fixed_asgp.py`).
- The optional `gagp_test_fixed_asgp_bench` CTest checks known solutions,
  population translation and the five fixed-generation modes.
